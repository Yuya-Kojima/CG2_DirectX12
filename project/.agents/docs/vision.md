# 全体ビジョン：パンツァードラグーン風ステージ制作システム

## 概要
「旅している感覚」のあるレールシューターステージを、AIツールとエンジン改修の2本立てで実現する。

---

## 構成図

```
[ 外部AIツール（新規制作） ]
  自然言語でステージを記述
        ↓ AI生成
  level_editor.json
        ↓ ロード
[ 自作エンジン（改修） ]
  Catmull-Romスプライン（実装済み）+ バンク計算で「旅の感覚」を再現
```

---

## Part 1 : 外部AIツール（新規制作）

### 入力
自然言語でのステージ記述
```
「廃墟の遺跡を低空飛行するステージ。
  石柱の間を縫うように右旋回し、
  最後は崖の上から急降下してボス戦へ。
  前半は偵察型の少数敵、後半は大群で圧迫。」
```

### AIが生成するもの
| データ | 内容 |
|---|---|
| `railWaypoints` | レールの経路座標列（カーブ・旋回・急降下を含む） |
| `railSpeed` | 速度 |
| `sceneObjects` | 地形オブジェクトの配置（位置・回転・スケール・モデル名） |
| `spawnEvents` | 敵ウェーブ（出現時刻・位置・種類・個別移動ルート） |

### 出力 : level_editor.json（拡張版）
```json
{
  "railWaypoints": [
    {"x": 0,  "y": 4,  "z": 0},
    {"x": 10, "y": 4,  "z": 50},
    {"x": 10, "y": 2,  "z": 100},
    {"x": -5, "y": 0,  "z": 150}
  ],
  "railSpeed": 0.2,
  "sceneObjects": [
    {
      "modelPath": "resources/pillar.obj",
      "position": [8, 0, 60],
      "rotation": [0, 0, 0],
      "scale": [2, 5, 2]
    }
  ],
  "spawnEvents": [
    {
      "spawnTime": 5.0,
      "prefabName": "ZakoEnemy",
      "spawnOffset": [5, 0, 50],
      "waypoints": [[5, 0, 40], [-2, 1, 30], [0, 0, 10]],
      "moveSpeed": 3.0
    }
  ]
}
```

### AIへの文脈情報（コンテキスト）
- 利用可能なモデル名一覧
- 利用可能なプレハブ名一覧
- ワールドスケール基準
- レール全体の目安時間

### ツールの構成
ロゴアニメーションツールと同じアーキテクチャ：
- Python + Gemini API でJSON生成
- C++アプリでプレビュー（レール経路とオブジェクト配置を3D表示）

## Part 2 : エンジン改修

### 2-1. RailCamera の改修
| 機能 | 現状 | 改修後 |
|---|---|---|
| 補間方式 | Catmull-Romスプライン | **実装済み** |
| ヨー・ピッチ | 実装済み | **実装済み** |
| カメラロール（バンク） | なし | **追加** |
| 速度可変 | なし | **追加（任意）** |
| カメラ慣性・ラグ | なし | **追加（任意）** |

### 2-2. 敵ウェイポイント追従（BehaviorWaypoint）
新規クラスとして追加。既存の IEnemyBehavior を継承。

### 2-3. SpawnEvent の拡張
`waypoints[]` と `moveSpeed` フィールドを追加。

### 2-4. level_editor.json の読み書き拡張
LoadLevel / SaveLevel を新フォーマットに対応。

---

## 実装フェーズ

```
Phase 1（エンジン）
  └── RailCamera : バンク計算の実装

Phase 2（エンジン）
  └── BehaviorWaypoint クラスの実装
  └── SpawnEvent に waypoints + moveSpeed を追加
  └── LoadLevel / SaveLevel の拡張

Phase 3（外部ツール・新規プロジェクト）
  └── AIがlevel_editor.jsonを生成するPythonスクリプト
  └── C++プレビューアプリ（レール経路・オブジェクト確認用）
```
